# gersang-market-releases

첫 테스트 버전입니다.

## 설치
1. 오른쪽 Releases에서 최신 gersang-market-setup-버전.exe를 받아 실행합니다. (관리자 권한 필요 없음)
2. 게임 패킷을 읽으려면 Npcap이 필요합니다. 없다면 https://npcap.com 에서 설치하세요.
   설치할 때 "Restrict Npcap driver's access to Administrators only"는 체크하지 마세요.
3. 설치할 때 "윈도우 시작 시 트레이로 실행"이 기본으로 켜져 있습니다. 원하지 않으면 해제하세요.
